# Contributing

The most valuable thing you can send is a **rule table from a grid that is not here yet** (MISO, NYISO, ISO-NE, AESO, a European TSO, a utility tariff), or a **correction** to one that is.

## Adding a grid

Open an issue with:

1. The document: title, date, URL, and the section or table number.
2. Its status: adopted, in force, proposed, or straw proposal.
3. The voltage ride-through table exactly as written (bands and minimum times), and the power-recovery deadline if the document has one.
4. Where the voltage is measured (POI, Service Delivery Point, other).

Every value must come from a public primary document. Summaries, slides about a draft, and news articles are not enough on their own.

## Corrections

If a value here is wrong, or a rule has changed since the date shown, open an issue quoting the sentence from the source that shows it. Corrections are fixed first and listed in [CHANGELOG.md](CHANGELOG.md).

## What this repository is not

It compares written rules. It does not certify any facility, and nothing here is a compliance determination.
